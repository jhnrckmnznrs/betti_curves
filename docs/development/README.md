# Development archive

This directory preserves optimization investigations, ablation notes, and candidate-history documents that are useful to maintainers but distracting in the public repository root.

- `investigations/`: targeted memory, data-structure, sweep, and reducer studies.
- `history/`: version-candidate notes and the detailed internal changelog from the optimization campaign.

These files are historical engineering records. Current behavior is documented by the root README, `docs/architecture.md`, source tests, and the current `CHANGELOG.md`.
